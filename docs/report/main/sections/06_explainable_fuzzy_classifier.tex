\section{Task 4: Explainable fuzzy classifier (10\%)}
Build an interpretable fuzzy system using KDEF frontal images and \textbf{3--10 handcrafted geometric facial features}, for example normalized mouth opening, mouth width, eye opening, eyebrow height and smile ratio. Landmarks may be obtained using OpenCV or dlib.

\fillme{Name each measured feature and normalization; specify fuzzy memberships (e.g., low/medium/high), rule base, inference/defuzzification and handling of missing landmarks. Include 1--2 representative readable IF--THEN rules and how they were chosen.}

\fillme{Report accuracy, balanced accuracy, macro-F1 and an appendix confusion matrix on held-out KDEF subjects; compare with conventional classifiers. Explain whether the learned/designed rules match plausible expression patterns and provide counterexamples.}
