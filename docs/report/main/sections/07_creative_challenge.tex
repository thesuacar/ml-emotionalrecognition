\section{Task 5: Creative challenge}
\label{sec:creative}

Starting from Task 1 baseline, each technique tested one change at a time, using a fast Logistic Regression and the validation split (PublicTest). Table~\ref{tab:creative} gives the ablation. The test split was used once, for the final model.
\textbf{Changes tested.}
\begin{itemize}
\item \textbf{Feature engineering (kept).} The 136 landmark values were appended to the 900 HOG features (1,036 features). HOG describes texture around the mouth and eyes, and landmarks describe the shape of the face, so the two carry different information.
\item \textbf{Data cleaning (kept).} Training images were fingerprinted with MD5 hashes. Duplicates with the same label were reduced to one copy, and images whose copies disagreed in label were removed (107 images), reducing the training set from 28,709 to 27,434 images. The gain is within the noise level (Section~\ref{sec:task1}).
\item \textbf{Class balancing (rejected).} Balanced class weights lowered both macro-F1 and Disgust F1, so the switch was left off.
\item \textbf{Augmentation (rejected).} Mirrored copies of the training images (with the landmarks reflected to match) doubled the training set. Macro-F1 went from 0.455 to 0.452 and Disgust F1 from 0.325 to 0.295, so the mirrored copies were left out of the final model.
\end{itemize}

\textbf{Final model.} The tuned Task 1 SVM ($C = 10$) was retrained on the kept changes: 1,036 features and the cleaned training set. Because the feature count rose from 900 to 1,036, $\gamma$ was rescaled by $900/1036$ to keep the kernel width comparable ($\gamma \approx 9.7\times10^{-4}$). This rescaling is a heuristic and was not tuned. On validation, the model reaches 0.607 accuracy and 0.598 macro-F1, against 0.562 for the tuned Task 1 SVM. On the test split, evaluated once, it reaches 0.594 accuracy, 0.572 balanced accuracy and 0.592 macro-F1, against 0.568 for the Task 1 SVM. Its confusion matrix is in Figure~\ref{fig:creative-confusion} (Appendix~\ref{app:cm}).

\textbf{Interpretation.} Adding landmarks is the main gain (+0.058 macro-F1 for Logistic Regression), and it is consistent with the landmark-based Random Forest in Task 1, which is the best classifier on landmarks. Cleaning changes the score by 0.002, which we treat as no effect. Class balancing hurt, even though Disgust recall was low (0.25) in Task 1. The notebook does not analyze why, so we leave the mechanism open. The test gain of 0.024 macro-F1 over Task 1 is not tested for significance, and the Task 1 bootstrap interval for macro-F1 is about $\pm0.023$. Two limitations apply. The ablation uses Logistic Regression, not the final SVM, and each step is a single run. The test split still contains the 8\% of images that also appear in training (Section~\ref{sec:task1}). KDEF-derived features were not used in the final model.
