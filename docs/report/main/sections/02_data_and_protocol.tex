\section{Datasets, preprocessing and experimental protocol}
\label{sec:data}
\textbf{FER2013 provenance and protocol:} FER2013 was introduced by \textcite{goodfellow_challenges} as part of a Kaggle challenge. Images were collected automatically from web image searches and labelled with seven emotion categories, and the authors report human accuracy of roughly 65\%. We used the provided Training, PublicTest and PrivateTest splits without re-splitting. The Training split fitted all models, PublicTest was used for model comparison and tuning, and PrivateTest was used once per tuned model. All classifiers use seed 42, and the bootstrap intervals use 1,000 resamples (seed 0). The software versions used for each task are listed in Table~\ref{tab:environments} (Appendix~\ref{app:env}).

\textbf{Preprocessing and face detection:} FER2013 images are already cropped 48 $\times$ 48 grayscale faces, so no detection or resizing was applied. HOG was computed on the raw image, and PCA used pixels scaled to $[0, 1]$. For landmarks, the whole image is passed to \textit{dlib} as the face box, so there are no detection failures by construction. The cost is that landmark quality depends on the crop being well aligned, which fails for tilted, occluded or off-centre faces (Figure \ref{fig:err-gallery} in Appendix \ref{app:figs}).

\textbf{Quality checks:} Exact duplicates were found by MD5 hashing. 280 of 3,589 validation images (7.8\%) and 288 of 3,589 test images (8.0\%) also appear in the training split. We kept duplicates in all Task 1 evaluation splits, so results stay comparable to the provided protocol, and we report non-duplicated scores separately (Section \ref{sec:task1}). Duplicates were removed from the training set only in Task 5 (section \ref{sec:creative}).

\textbf{Limitations:} The dataset has strong class imbalance (Disgust is 1.5\% of training, see Figure \ref{fig:fer-dist} and Table \ref{tab:fer-counts} in Appendices \ref{app:figs} and \ref{app:tables}), noisy or ambiguous labels, low resolution, and cross-split leakage through duplicates. Examples of the first two issues are shown in Figure \ref{fig:err-gallery} (Appendix \ref{app:figs}).

\textbf{KDEF.} This database was presented by \textcite{goeleven_karolinska}, but for this assignment, we use only straight/frontal (S) faces, across seven comparable expressions (KDEF ``Afraid'' maps to FER ``fear''). Divide by identity: 80\% of subjects for training, 20\% for testing, with no subject overlap.

\textbf{Common representation:} Detect and crop KDEF faces with a margin preserving forehead and jaw; convert to grayscale, resize to $48\times48$ and apply the same normalization as FER. Apply identical feature extraction at training and inference. Fit any scaling, PCA or learned transformation only on training data.

\textbf{HOG features:} Histogram of Oriented Gradients (HOG) describes the local edge directions of an image. Each $48\times48$ image is described by 900 HOG features (9 directions in each of $2\times2$ cells, over $5\times5$ overlapping block positions). The derivation is given in Appendix~\ref{app:hog}.

\textbf{Fuzzy classifier protocol:}
For Task 4, geometric features were extracted directly from original-resolution frontal KDEF images, rather than the FER-compatible $48\times48$ images. Both acquisition sessions for each identity remained in the same partition. Model selection used training subjects only, preserving the held-out KDEF subjects for final evaluation.
