\subsection{Assignment Questions}

\paragraph{What adaptations did you have to make to run the model?}
As mentioned before, the format of images in both datasets is very different.  The color map, dimensions etc. of KDEF are not the same as FER2013. As images of FER2013 are all grayscale, it cannot be converted into the same format of KDEF because we can't recover the missing colour information. Therefore, KDEF is converted it to grayscale, resized it to $48 \times 48$ pixels and scaled the pixel values to between 0 and 1. FER2013 images are already that size, so they only needed rescaling.

Once both datasets are pre-processed into the same format, we run the HOG feature extraction to convert the $48 \times 48$ into 900 features, which will be used by the SVM for classification.

\paragraph{What is domain shift?}
Domain shift is when a model is trained on one dataset and is tested on a different dataset. This helps in understanding how well the model has generalized the patterns for classification. This did not succeed well between the KDEF and FER2013 because of the following reasons: 

\begin{itemize}
   
    \item \textbf{Source of images} FER2013 images are publicly available images,and there is no selection criteria when the dataset was created. The only criteria was if the emotion is being displayed, and there is no consistency on the subject, the orientation, facial features/attributes. Emotion expression in FER2013 are less obvious, and the labels are not always correct. KDEF images were taken in a controlled environment, and all subjects were given explicit instructions during the data collection. The subjects in KDEF make each emotion easy to read. 
    \item \textbf{Imbalanced dataset} KDEF has the same number of images for each emotion. FER2013 does not: 25\% of its images are Happy, but only 1.5\% are Disgust (Figure 5.2.1, left). For a model like SVM, an imbalance in dataset can definitely affect its performance
\end{itemize}

We then checked whether these differences are also visible in the HOG features our model uses. To do this, we trained a simple classifier to predict which dataset an image came from. We used all 980 KDEF images and a random sample of 980 FER2013 images (140 per emotion randomly chosen), so both sets had the same size and the same emotion mix. The classifier reached a balanced accuracy of 98.8\% (5-fold cross-validation). This proved that the HOG features are different enough for a model to understand which dataset an image would belong to.

\textbf{Why does performance degrade?} In short, the model was trained on images from controlled studio environment of 70 people facing the camera. FER2013 had no specific environment, and were images of random subjects

Our choice of features makes this harder still. HOG splits the image into a fixed grid of cells and records the direction of the edges in each cell, so every feature is tied to a specific location in the image. In KDEF, the eyes, eyebrows and mouth always fall into the same cells, and the model learns which cells matter for each emotion. In FER2013, faces are often shifted, tilted or cropped differently, as the mean faces in Figure 4.3.1 show, so the same facial features land in different cells. Even when the expression is identical, the resulting gradient pattern can look very different from anything the model saw during training. This is also why a simple classifier could separate the two datasets with a balanced accuracy of 98.8\% using HOG features alone.

\textbf{Which features transfer best?} Since our model relies only on HOG, we looked at which of its 900 features carry over best to FER2013. For each feature, we calculated its average value per emotion, once in KDEF and once in FER2013, and then compared the two patterns using a correlation. A correlation close to 1 means the feature rises and falls with the emotions in the same way in both datasets, so what the model learned from it still holds on FER2013.

Looking at Figure~\ref{fig:cross-hog} and Table~\ref{tab:cross-hog-features}, it is evident that the features around the centre of the face transfers better. Features around the eyes, mouth and cheeks, which are the regions that actually express emotion, keep almost the same pattern in both datasets, with correlations as high as 0.95. Most of the features with low correlation are outside the face.

If the central features transfer so well, why does the model still perform so poorly on FER2013? Correlation only captures part of the picture. It compares the average feature value for each emotion, but the model classifies individual images, not averages. Individual FER2013 images vary much more than KDEF images because of differences in alignment, pose and lighting, so even in the best features the emotions overlap heavily. The values themselves are also shifted relative to KDEF, which pushes many images to the wrong side of the boundaries the SVM learned. Finally, the SVM does not get to pick only the good features: it uses all 900 at once, including the edge features that point in the opposite direction.
